# 메시지 체계

브로커가 Slack 에 올리는 모든 것의 유형과 규격. 새 메시지를 추가하거나 문구를 고칠 때 이 표에 맞춘다.
기준일 2026-09-23. 아래 "현재 어긋난 것" 은 그날 정리하며 고쳤거나 남긴 것.

## 원칙

1. **첫 글자가 유형이다.** 아이콘 하나가 한 유형에만 쓰인다. 폰에서 스크롤하며 아이콘만 봐도 "결정해야 하나, 알림인가, 오류인가" 가 갈린다.
2. **결정이 필요한 것만 사람을 부른다.** 멘션(`@사용자`)은 결정 카드와 그 리마인더에만 붙는다. `:notify` 가 그 범위를 조절한다.
3. **살아 있는 것은 제자리에서 바뀐다.** 상태·진행·대기 안내는 새로 올리지 않고 한 메시지를 갱신하고, 끝나면 지우거나 결과 한 줄로 접는다. 스레드에 쌓이는 것은 사람의 말, Claude 의 답, 결정의 결과뿐이다.
4. **버튼은 결정 카드에만, 한 줄에 셋 이하.** 기본 선택은 `primary` 하나, 위험한 것은 `danger` 하나. 버튼을 누르면 카드는 결과 한 줄로 접힌다.
5. **오류는 세 조각이다.** 무슨 일이 났나 · 왜 · 이제 무엇을 하면 되나. 코드(`invalid_blocks`)는 남기되 문장 뒤에.
6. **응답은 부른 쪽으로.** 버튼을 눌러 생긴 확인은 누른 사람에게만(ephemeral), 스레드에 쳐서 생긴 확인은 스레드에.
7. **한 문장은 한 줄.** 안내 문구는 두 문장을 넘기지 않는다. 설명이 더 필요하면 `:help` 로 보낸다.

## 유형과 규격

| 유형 | 아이콘 | 예 | 멘션 | 버튼 | 수명 |
|---|---|---|---|---|---|
| **A. 상태** 루트 줄 · 컨트롤 패널 · 홈 탭 | 🟢 대기 · 🔵 작업 중 · 🟡 응답 필요 · ⚫ 종료 · 🚀 시작 중 | `🟡 *proj* · ~/proj · 응답 필요` | 없음 | 패널의 ⚙️ 설정과 ⋯ 만 | 세션이 사는 동안 제자리 갱신 |
| **B. 흐름** 답변 스트림 · 도구 카드 · 할 일 | (없음) 답변은 본문 그대로, 도구는 카드 | `⚙️ Bash npm test · 1분 20초` | 없음(`:notify on` 이면 답변 끝에) | 없음 | 턴 동안 스트림, 끝나면 그대로 남음 |
| **B'. 입력 미러** 터미널에서 친 것 | ⌨️ | `⌨️ 테스트 돌려줘` | 없음 | 없음 | 남음 (600자 넘으면 접음) |
| **B''. 서브에이전트 보고** | 🤖 | `🤖 *서브에이전트 보고*` + 본문 | 없음 | 없음 | 남음 |
| **C. 결정 카드** 권한 · 질문 · 플랜 · 터미널 창 · 정지 | 🔐 · ❓ · 📋 · ⌨️ · ⏸️ | `@user 🔐 *Bash* 권한 요청 · abcde` | **있음**(`:notify off` 면 없음) | 있음 | 답하면 결과 한 줄로 접힘 (`✅ 허용 · abcde · @user`) |
| **D. 진행 안내** 붙잡음 · 조용함 · 준비 중 | 🕓 붙잡음 · ⏳ 조용함/준비 중 | `🕓 메시지 1개를 붙잡고 있습니다` | 없음 | 붙잡음만 (⚡ 지금 보내기 · 취소) | 제자리 갱신, 끝나면 **삭제** |
| **D'. 리마인더** | ⏰ | `@user ⏰ 5분째 권한 응답을 기다리고 있습니다` | 있음 | 없음 | 남음 (한 번, 그다음은 DM) |
| **E. 확인 응답** 명령의 결과 | ⏹️ 멈춤 · ▶️ 계속 · → 명령 전달 · ✏️ 이름 · 👁 보기 · 🔔 알림 · ☑️ 선택 · 📨 전달 | `⏹️ 멈췄습니다. 다음 지시를 기다립니다.` | 없음 | 없음 | 남음, 버튼에서 왔으면 ephemeral |
| **F. 시스템 이벤트** | 🧹 초기화 · 📦 압축 · 🔄 되살림 · ↩️ 자동 확인 · ⚫ 종료 | `⚫ 세션 종료 (exit)` | 없음 | 없음 | 남음 |
| **G. 오류** | ⚠️ 조치 필요 · ❌ 실패 · 🚫 거부됨 | `⚠️ 파일을 올릴 권한이 없습니다. Slack 앱에 files:write 를 추가하고 재설치하세요.` | 없음 | 없음 | 남음 |
| **H. 도움말** | (없음) | `:help`, `/cchelp` | 없음 | 없음 | ephemeral 우선 |

### 아이콘 사전 (하나에 하나)

| 아이콘 | 뜻 | 아이콘 | 뜻 |
|---|---|---|---|
| 🟢 🔵 🟡 ⚫ 🚀 | 세션 상태 | 🔐 ❓ 📋 ⌨️ ⏸️ | 결정 카드 (권한·질문·플랜·터미널 창·정지) |
| 🕓 | 메시지를 붙잡고 있음 | ⏳ | 기다리는 중 (조용함, 세션 준비) |
| ⏰ | 리마인더 | ✅ ⛔ ☑️ | 결정의 결과 (허용·거부·선택) |
| ⏹️ ▶️ | 멈춤 · 계속 | → | 터미널에 명령을 넣었음 |
| ✏️ 👁 🔔 📨 | 이름 · 보기 · 알림 · 다른 세션에 전달 | 🧹 📦 🔄 ↩️ | 초기화 · 압축 · 되살림 · 자동 확인 |
| ⚠️ | 조치가 필요한 문제 | ❌ 🚫 | 실패 · 거부됨 |
| 🤖 | 서브에이전트 | ⌨️ (미러) | 터미널에서 친 입력 |

`⌨️` 만 두 자리(입력 미러, 터미널 창 카드)에 쓰인다. 카드는 굵은 제목과 버튼이 있어 구분되지만, 자리가 생기면 카드를 🖥 로 옮긴다.

### 반응(reaction) 사전

| 반응 | 뜻 |
|---|---|
| 👀 | 세션에 전달됨 |
| ✅ | 그 메시지에 대한 턴이 끝남 |
| 🕓 | 붙잡혀 있음 (도구가 끝나면 전달) |
| ❌ | 취소로 버려짐 |

## 각 유형의 규격

**A. 상태.** 루트 줄은 `아이콘 *이름* · 경로 · 상태문` 한 줄과 `모델 · effort · 권한 · 컨텍스트` 한 줄. 응답이 필요하면 상태문이 `🟡 권한 대기 3분` 처럼 이유와 경과를 담는다. 패널은 같은 두 줄 + ⚙️ 설정 + ⋯ 메뉴. 홈 탭은 응답 필요한 세션을 먼저.

**C. 결정 카드.** 첫 줄 `@user 아이콘 *무엇* · id`. 둘째 블록에 결정에 필요한 것(diff, 명령, 선택지 설명). 버튼 행 하나. 답하면 `✅ 허용 · abcde · @user` 처럼 결과 한 줄로 접히고 버튼은 사라진다. 카드가 사라진 뒤 눌린 버튼은 "그 창은 이미 닫혔습니다" ephemeral.

**D. 진행 안내.** 세션당 하나씩(붙잡음 하나, 조용함 하나). 상황이 바뀌면 같은 메시지를 갱신하고, 끝나면 지운다. 조용함 안내는 90초 넘게 새 출력이 없을 때만 뜨고, 도구가 돌고 있으면 무엇이 도는지, 아니면 상태 문장을 쓴다. 화면 원문은 `:screen` 으로 미룬다.

**E. 확인 응답.** 한 줄. 무엇을 했고 결과가 무엇인지(`⏹️ 멈췄습니다` / `⏹️ 이미 유휴 상태였습니다`). 버튼에서 온 명령이면 ephemeral, 쳐서 온 명령이면 스레드.

**G. 오류.** `⚠️ 무슨 일. 왜. 다음 행동.` 사용자 조치 없이 브로커가 스스로 넘어간 것은 로그에만 남기고 스레드에 올리지 않는다.

## 현재 어긋난 것과 조치 (2026-09-23)

| 어긋남 | 조치 |
|---|---|
| 루트 줄은 🟢🟠⚫, 패널·홈은 🟢🔵🟡⚫ 로 상태 색이 달랐다 | 루트 줄도 🟢🔵🟡⚫🚀 로 통일 (고침) |
| ⏳ 가 세 자리(준비 중, 조용함, 재시도 안내)에 쓰였다 | 재시도 안내는 결정 카드의 후속이므로 ⏳ 대신 결과 접기 문구로; 준비 중과 조용함은 둘 다 "기다림" 이라 ⏳ 유지 |
| 조용함 안내가 턴이 끝나도 남아 "3분째 새 출력이 없습니다" 가 굳어 있었다 | 턴이 끝나면 삭제 (고침) |
| 정지 카드(⏸️)가 ▶️ 계속해 뒤에도 버튼을 단 채 남았다 | 누르면 `▶️ 계속해 · @user` 로 접힘 (고침) |
| `⚠️ 세션과의 연결이 없습니다.` 처럼 다음 행동이 없는 오류가 있었다 | 세 조각 형식으로 (고침) |
| `⏹️ 중단하려면 :esc 를 입력하세요` 는 확인이 아니라 안내인데 ⏹️ 를 썼다 | 안내는 아이콘 없이 (고침) |
| `:notify` `:view` 는 버튼이 없어 스레드에만 답한다 | 규칙대로 (변경 없음) |
| `⌨️` 가 입력 미러와 터미널 창 카드에 겹친다 | 남김. 카드는 제목·버튼으로 구분된다 |
| 리마인더가 새 메시지로 쌓인다 | 의도. 폰을 울리려면 새 메시지여야 한다 |
